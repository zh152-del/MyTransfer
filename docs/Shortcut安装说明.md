# 「接收电脑文件」快捷指令安装说明

## 方式一：直接导入（先试这个）

1. 把 `shortcut/接收电脑文件.shortcut` 通过 AirDrop / 微信文件传输助手 /
   数据线「文件」App 传到 iPhone。
2. 在 iPhone 的「文件」App 里点一下这个文件 → 会自动跳到「快捷指令」App。
3. 出现授权弹窗时点「允许」（访问本地网络）。
4. 完成。以后在电脑上选好文件，iPhone 上点一下「接收电脑文件」快捷指令即可。

**⚠ 诚实说明（重要）**：
- 这个文件按 Shortcuts 的标准格式生成，但没有真机环境，**未经 iPhone 实际导入验证**。
- **iOS 15 及以上，系统会拒绝导入「未经 Apple 签名」的快捷指令文件**——这是 Apple
  的安全策略。如果你的 iPhone 导入时报「无法导入 / 未经签名」，**不是你操作错了**，
  请直接用下面的「方式二」手动搭，一共 10 个动作，每个动作的网址都写死了，
  照着点一遍就行（大约 5 分钟）。

## 方式二：手动搭建（10 个动作，全部照抄即可）

打开「快捷指令」App → 右上角「+」新建 → 依次添加以下动作。
**所有网址直接照抄，不用改任何 IP / 端口 / 变量以外的内容。**

| # | 动作（在搜索框输入加粗词） | 怎么填 |
|---|---|---|
| 1 | **获取 URL 内容** | 网址填 `http://MyTransfer.local:8765/api/shortcut/status` |
| 2 | **获取词典值** | 左边格选上面动作的输出「URL 的内容」，键填 `hasFile` |
| 3 | **如果** | 输入选「词典值」，条件选「等于」，填 `true` |
| 4 | **获取词典值** | 输入选「URL 的内容」，键填 `fileName` |
| 5 | **获取词典值** | 输入选「URL 的内容」，键填 `fileUrl` |
| 6 | **获取 URL 内容** | 网址选「词典值」（fileUrl 那个） |
| 7 | **保存文件** | 关掉「询问存储位置」，目标路径填 `/MyTransfer`，开「覆盖文件」 |
| 8 | **获取 URL 内容** | 网址填 `http://MyTransfer.local:8765/api/shortcut/complete` |
| 9 | **显示通知** | 内容填 `接收完成，已保存到「文件 → 我的 iPhone → MyTransfer」` |
| 10 | **否则** → 在第 10 行加**显示通知**，内容填 `电脑当前没有待接收文件` → 最后加**结束如果** | —— |

搭完把快捷指令重命名为 **接收电脑文件**。

首次运行会弹「允许访问本地网络」，点允许。

## 运行后的样子

- 有文件：通知「接收完成，已保存到 文件 → 我的 iPhone → MyTransfer」，
  电脑端日志出现「快捷指令 下载文件 / 回报接收完成 / [OK] 字节数一致」。
- 没文件：通知「电脑当前没有待接收文件」。
- 连不上电脑：快捷指令报错——检查 ① 电脑程序在运行（双击桌面 `MyTransfer.bat`）
  ② 手机和电脑在同一 Wi-Fi。

## 为什么不用填 IP

网址里的 `MyTransfer.local` 是电脑端 Bonjour 广播的主机名，iPhone 会自动解析出
电脑的局域网 IP（电脑换了路由器、换了 IP 也不用改快捷指令）。
电脑端日志首行应有：`Bonjour 广播：MyTransfer.local -> <电脑IP>（含 A 记录 + 服务记录）`。
