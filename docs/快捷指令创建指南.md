# iPhone 快捷指令「文件接收」创建指南

照着本指南一步步点，**每一步写什么都是抄好的**，不用懂快捷指令编程。
全部搭完约 10 分钟。搭完的效果：电脑上选好文件 → iPhone 点一下快捷指令 →
照片/视频自动进相册，其它文件自动进「文件 → MyTransfer」→ 弹通知。

---

## 一、准备工作（30 秒）

1. 确认电脑端 MyTransfer 正在运行（双击桌面「握手」或 `MyTransfer.bat`，窗口右上角显示"服务运行中"）。
2. iPhone 和电脑连**同一个 Wi-Fi**。
3. Safari 打开这个地址测试（能看见一串 JSON 文字就说明通了）：
   `http://MyTransfer.local:8765/api/shortcut/status`

---

## 二、新建快捷指令

1. 打开「快捷指令」App → 右上角 **「+」** 新建。
2. 点顶部名字「快捷指令」→ 重命名为 **文件接收**（或你喜欢的名字）。
3. 依次添加下面的动作。**添加动作的方法**：点屏幕底部的搜索框 → 输入动作名 → 点它。

---

## 三、动作清单（共 17 个，按顺序）

### 【第 1 个动作】获取 URL 内容

- 搜索「**获取 URL 内容**」
- 网址栏填（一字不差抄）：

```
http://MyTransfer.local:8765/api/shortcut/status
```

### 【第 2 个动作】获取词典值 hasFile

- 搜索「**获取词典值**」
- 左边输入：选「**URL 的内容**」（第 1 步的输出）
- 键填：`hasFile`

### 【第 3 个动作】如果（有没有文件）

- 搜索「**如果**」
- 输入：选「**词典值**」（第 2 步的输出）
- 条件类型选「**有任何值**」（这个条件用"有任何值"就行，不用改）

> 下面第 4~13 个动作都在这个「如果」的**块里面**添加。

### 【第 4 个动作】获取词典值 fileName

- 「获取词典值」
- 输入：「URL 的内容」（第 1 步的）
- 键：`fileName`

### 【第 5 个动作】获取词典值 fileUrl

- 「获取词典值」
- 输入：「URL 的内容」（第 1 步的）
- 键：`fileUrl`

### 【第 6 个动作】获取词典值 kind

- 「获取词典值」
- 输入：「URL 的内容」（第 1 步的）
- 键：`kind`

> ⚠ **注意顺序**：第 4、5、6 这三个都必须在**下载动作之前**！
> 因为下载之后「URL 的内容」这个名字就变成下载的文件了，
> 再取 kind 会报「无法将媒体转换为词典」。

### 【第 7 个动作】下载文件

- 「**获取 URL 内容**」
- 网址栏：选「**词典值**」（第 5 步 fileUrl 的输出）

### 【第 8 个动作】匹配文本（抓扩展名）

- 搜索「**匹配文本**」
- 输入：「**词典值**」（第 4 步 fileName 的输出）
- 匹配文本框填这段（长按复制过去，一个字符别改）：

```
[^.]+$
```

（意思是：抓文件名最后一个点后面的内容 = 扩展名）

### 【第 9 个动作】如果（扩展名判断）—— 用来存相册

- 「**如果**」
- 顶部条件组选「**任一**」为真
- 点「添加条件」，把下面 10 条全部加上，每条都是：
  - 输入选「**匹配文本**」（第 8 步的输出）
  - 类型「是」
  - 值分别填：`JPG`、`JPEG`、`PNG`、`HEIC`、`HEIF`、`GIF`、`WEBP`、`MP4`、`MOV`、`M4V`
- 这个 If 的块里放一个动作：
  - 「**存储到相册**」（搜索"存储到相册"，相册选「**最近项目**」）
  - 输入：选「**URL 的内容**」——**注意选下载那一步（第 7 个动作）产生的「URL 的内容」**，
    列表里有两个同名的时候，选**靠下的**那个。

### 【第 10 个动作】否则（其它文件类型）—— 存到文件 App

- 点第 9 个 If 动作，加「**否则**」
- 否则块里放：
  - 「**保存文件**」
  - 输入：「URL 的内容」（同样是**下载那步**的输出）
  - 关闭「询问存储位置」
  - 目标路径：`/MyTransfer`
  - 打开「覆盖文件」

### 【第 11 个动作】kind 兜底判断（可选，但建议加）

在第 10 个「否则」块里、保存文件**之前**，再加一层判断——
这样就算某天扩展名没匹配上，只要电脑标了 photo/video 也照样进相册：

- 「**文本**」动作：内容选「**词典值**」（第 6 步 kind 的输出）
- 「**如果**」：输入选「**文本**」，类型「**任一**」为真
  - 条件 1：文本 是 `photo`
  - 条件 2：文本 是 `video`
  - 块里放「**存储到相册**（最近项目）」，输入选「**URL 的内容**」（下载那步的）
- 加「**否则**」→ 把「保存文件」放这里
- 加「**结束如果**」

### 【第 12 个动作】结束第一个如果

在第 9~11 的所有判断外面，要有第一个 If 的「**结束如果**」。

### 【第 13 个动作】回报电脑「我收完了」

- 「**获取 URL 内容**」
- 网址填（照抄）：

```
http://MyTransfer.local:8765/api/shortcut/complete
```

### 【第 14 个动作】完成通知

- 「**显示通知**」
- 内容填：`接收完成，文件已保存`

### 【第 15 个动作】否则（没有文件时）

- 点第 3 个 If，加「**否则**」
- 块里放「**显示通知**」，内容填：`无文件，请上传`

### 【第 16 个动作】结束如果

最外层 If 的「**结束如果**」。

---

## 四、搭完后的完整顺序（自检用）

```
1  获取 URL 内容        …/api/shortcut/status
2  获取词典值 hasFile
3  如果 词典值 有任何值
4    获取词典值 fileName
5    获取词典值 fileUrl
6    获取词典值 kind          ← 必须在下载前
7    获取 URL 内容（词典值）   ← 下载
8    匹配文本（fileName，[^.]+$）
9    如果 任一(JPG/…/M4V) → 存储到相册
10   否则 ｛
11     文本(kind)
12     如果 任一(photo/video) → 存储到相册
13     否则 → 保存文件到 /MyTransfer
14     结束如果 ｝
15   结束如果
16   获取 URL 内容        …/api/shortcut/complete
17   显示通知「接收完成，文件已保存」
否则 → 显示通知「无文件，请上传」
结束如果
```

## 五、常见坑（都踩过）

| 症状 | 原因 | 解决 |
|---|---|---|
| 报「无法将文本转换为词典」 | 「如果」的输入选了整段 JSON 而不是 hasFile 词典值 | If 输入改选「词典值」 |
| 报「无法将媒体转换为词典」 | kind 的词典值放在了**下载之后**，「URL 的内容」变成文件了 | 把 kind 那步挪到下载**之前** |
| 全都存进了文件，没进相册 | 扩展名取的是下载文件（没有扩展名，恒为空） | 扩展名从 **fileName 匹配文本**取；再加 kind 兜底 |
| 存出来是个小 json 文件 | 「保存文件」的输入选成了 status 的「URL 的内容」 | 改选**下载那步**的「URL 的内容」 |
| 最后一步报「无法转换为 URL」 | complete 的网址框里插了变量 | 清掉变量，**纯键盘打字**填网址 |
| 提示无法连接 | 电脑没开 / 不同 Wi-Fi | 先用 Safari 测第一节的地址 |

## 六、首次运行授权

第一次运行会依次弹：
1. 「允许"快捷指令"访问本地网络」→ 允许
2. 「允许访问照片」→ 允许所有照片（不然后面存不了相册）

## 七、日常使用

1. 电脑上选好文件（窗口里显示"准备就绪，等待 iPhone 取文件"）。
2. iPhone 点「文件接收」快捷指令。
3. 弹「接收完成，文件已保存」→ 相册或「文件 → MyTransfer」里看。
4. 电脑窗口日志出现 `[OK] 字节数 xx/xx 一致` = 校验通过。

## 八、换个电脑 / 换 Wi-Fi 怎么办

网址里的 `MyTransfer.local` 是电脑的 Bonjour 名字，电脑换了 IP 不用改。
如果换了台电脑当服务器，把三个网址里的 `MyTransfer.local:8765` 换成新电脑的 `IP:8765` 即可（共 2 处：status 和 complete）。
