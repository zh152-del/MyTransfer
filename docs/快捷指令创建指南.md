# iPhone 快捷指令「文件接收」超详细创建教程

> 本教程细到**每一次点击、每一个框填什么字**。全程照抄即可，约 10 分钟。
> 搭完效果：电脑选好文件 → iPhone 点一下 → 照片/视频自动进**相册**，
> 其它文件自动进「文件 App → MyTransfer」→ 弹「接收完成」通知。

---

## 准备：开始之前确认 3 件事

1. 电脑端 MyTransfer 正在运行（双击「握手」或 MyTransfer.bat，右上角显示"服务运行中"）。
2. iPhone 和电脑连的是**同一个 Wi-Fi**。
3. iPhone 的 Safari 打开下面这个地址，能看到一串 `{ "hasFile" ... }` 文字 = 网络通：

   ```
   http://MyTransfer.local:8765/api/shortcut/status
   ```

---

## 第 0 步：新建空快捷指令

1. 打开 iPhone 的「**快捷指令**」App。
2. 点右上角 **「＋」** 号。
3. 点顶部的名字「快捷指令」→ 改成 `文件接收` → 点「完成」。

**添加动作的通用方法**（下面每一步都用这个方法）：
点屏幕底部的 **🔍 搜索动作** 输入框 → 打动作名的前几个字 → 点搜索结果里的那个动作。

---

## 第 1 步：添加「获取 URL 内容」（问电脑有没有文件）

1. 搜索并添加：**获取 URL 内容**（图标是绿色，带一个 ▶）。
2. 点动作里的网址框，**用键盘原样输入**（不要插任何变量）：

   ```
   http://MyTransfer.local:8765/api/shortcut/status
   ```

3. 「获取」右边保持默认的「内容」。

✅ 检查点：这一步单独点 ▶ 运行，应该显示一行 JSON（`{"hasFile": ...}`）。

---

## 第 2 步：添加「获取词典值」（取 hasFile = 有没有文件）

1. 搜索并添加：**获取词典值**（橙色图标）。
2. 「在 ___ 中」这个框：点它 → 选 **「URL 的内容」**（第 1 步输出的蓝色胶囊）。
3. 「获取 ___ 的值」这个框：输入 `hasFile`

此时动作显示：**在 URL 的内容 中获取 hasFile 的 值**。

---

## 第 3 步：添加「如果」（判断有没有文件）

1. 搜索并添加：**如果**（灰色 Y 图标）。
2. 「如果 ___ 」这个输入框：选 **「词典值」**（第 2 步的输出）。
3. 中间的条件类型：保持 **「有任何值」**（不用改成等于，hasFile 只要有值就是有文件）。

> ⚠ 这个 If 会自动带出「结束如果」，后面第 16 步会用到，别删。
> 第 4~14 步的所有动作都加在「如果」和「结束如果」**之间**。

---

## 第 4 步：获取词典值（取 fileName = 文件名）

在 If 块里添加：**获取词典值**

- 「在 ___ 中」：选 **「URL 的内容」**
- 「获取 ___ 的值」：输入 `fileName`

---

## 第 5 步：获取词典值（取 fileUrl = 下载地址）

在 If 块里添加：**获取词典值**

- 「在 ___ 中」：选 **「URL 的内容」**
- 「获取 ___ 的值」：输入 `fileUrl`

---

## 第 6 步：获取词典值（取 kind = 文件类型）⚠ 位置很重要

在 If 块里添加：**获取词典值**

- 「在 ___ 中」：选 **「URL 的内容」**
- 「获取 ___ 的值」：输入 `kind`

> ⚠⚠ **必须放在第 7 步「下载」的上面！**
> 下载之后「URL 的内容」这个名字就变成下载的文件了，再取 kind
> 会报「无法将媒体转换为词典」。顺序：fileName → fileUrl → kind → 下载。

---

## 第 7 步：添加「获取 URL 内容」（下载文件本体）

1. 搜索并添加：**获取 URL 内容**。
2. 网址框：**不要打字**！点框 → 选 **「词典值」**（第 5 步 fileUrl 的输出）。

✅ 这一步运行时就会把文件从电脑下载到手机（临时区）。

---

## 第 8 步：添加「匹配文本」（从文件名抓扩展名）

1. 搜索并添加：**匹配文本**（黄色图标）。
2. 「匹配 ___ 中的」：选 **「词典值」**（第 4 步 fileName 的输出）。
3. 「匹配文本」框：长按复制下面这串粘贴进去（一个字符都不能差）：

   ```
   [^.]+$
   ```

   （含义：抓文件名最后一个点后面的内容 = 扩展名，比如 `cat.jpg` 抓出 `jpg`）

> 不用「从 URL 的内容 获取文件扩展名」——下载下来的文件没有文件名，
> 扩展名永远是空，这就是之前"全部存进文件不进相册"的原因。

---

## 第 9 步：添加「如果」（扩展名判断 → 存相册）

1. 搜索并添加：**如果**。
2. 顶部条件左侧选 **「匹配文本」**（第 8 步的输出）。
3. 条件关系选 **「任一」为真**（很重要，默认可能是"全部"，点一下切换成「任一」）。
4. 点「**⊕ 添加条件**」，依次添加 **10 条**，每条都是：
   - 输入：**匹配文本**
   - 类型：**是**
   - 值分别是（一条一个）：

     `JPG` → `JPEG` → `PNG` → `HEIC` → `HEIF` → `GIF` → `WEBP` → `MP4` → `MOV` → `M4V`

5. 在这个 If 的块里面，添加动作：**存储到相册**
   - 它会显示「将 ___ 存储到 最近项目」
   - 「将 ___ 」这个输入：选 **「URL 的内容」**
   - ⚠ 现在列表里有两个「URL 的内容」（第 1 步的 JSON 和第 7 步的下载文件）。
     **选下面那个 / 属于第 7 步下载的**。选错了存出来的就是一个小 json。

---

## 第 10 步：给第 9 步的 If 添加「否则」（其它文件 → 存文件 App）

1. 点开第 9 步的「如果」动作卡片。
2. 在条件列表下方点「**添加“否则”**」？——如果没有这个按钮，就直接在块末尾添加动作：
   搜索 **否则** 并添加。
3. 在「否则」块里添加：**保存文件**
   - 「将 ___ 存储到」：选 **「URL 的内容」**（第 7 步下载的输出，和上一步同一个）
   - 关闭「**询问存储位置**」开关
   - 「目标路径」填：`/MyTransfer`
   - 打开「**覆盖文件**」开关

---

## 第 11 步：kind 兜底（可选但强烈建议）

这是第二道保险：扩展名没认出来的文件，只要电脑标了 photo/video 也进相册。
在第 10 步「否则」块里、「保存文件」的**上面**添加：

1. 添加「**文本**」动作：
   - 点文本框 → 点键盘上方的变量键 → 选「**词典值**」（第 6 步 kind 的输出）
   - ⚠ 必须是**蓝色胶囊变量**，不是手打的"词典值"三个字！
2. 添加「**如果**」：
   - 输入：选「**文本**」（刚才那个文本动作的输出——选了它，条件类型里才会出现「等于」）
   - 类型：**任一** 为真
   - 条件 1：文本 **等于** `photo`
   - ⊕ 添加条件 → 条件 2：文本 **等于** `video`
   - 块里放「**存储到相册（最近项目）**」，输入选「**URL 的内容**」（下载的）
3. 给这个内层 If 加「**否则**」→ 把「**保存文件**」拖进这个内层否则里。
4. 补一个「**结束如果**」收尾这个内层 If（动作库搜"结束如果"）。

---

## 第 12 步：补齐「结束如果」

检查第一个 If（第 3 步的）末尾有「**结束如果**」。两层 If = 两个结束如果，一个都不能少。

---

## 第 13 步：添加「获取 URL 内容」（告诉电脑我收完了）

在第一个「结束如果」**之后**添加：**获取 URL 内容**

网址用键盘原样输入：

```
http://MyTransfer.local:8765/api/shortcut/complete
```

> ⚠ 这个框里**不要插任何变量**，插了会报「无法将多信息文本转换为 URL」。

---

## 第 14 步：添加「显示通知」（完成提示）

- 搜索并添加：**显示通知**
- 内容填：`接收完成，文件已保存`

---

## 第 15 步：添加「否则」+ 无文件提示（收尾）

1. 滚动到最底部，点第 3 步 If 的「**否则**」（或添加一个否则）。
2. 否则块里添加「**显示通知**」，内容填：`无文件，请上传`
3. 最后确认最底部有整个最外层的「**结束如果**」。

---

## 全部搭完的自检清单

从上到下应该正好是：

```
 1  获取 URL 内容           …/api/shortcut/status     ← 键盘打的固定网址
 2  在 URL 的内容 中获取 hasFile 的值
 3  如果 词典值 有任何值
 4    在 URL 的内容 中获取 fileName 的值
 5    在 URL 的内容 中获取 fileUrl 的值
 6    在 URL 的内容 中获取 kind 的值            ← 必须在下载上面！
 7    获取 词典值 内容                          ← 下载
 8    匹配 词典值(fileName) 中的 [^.]+$
 9    如果 任一为真（匹配文本 是 JPG/…/M4V 共 10 条）
10      将 URL 的内容(下载的) 存储到相册·最近项目
11      否则 ｛
12        文本：词典值(kind)
13        如果 任一为真（文本 是 photo / video）→ 存储到相册
14        否则 → 保存文件到 /MyTransfer
15        结束如果 ｝
16    结束如果
17  获取 URL 内容           …/api/shortcut/complete    ← 固定网址，无变量
18  显示通知「接收完成，文件已保存」
19  否则 → 显示通知「无文件，请上传」
20  结束如果
```

## 测试（三样各来一次）

| 电脑上发什么 | 手机应该存到哪 |
|---|---|
| 一张 `.jpg` 图片 | 相册 → 最近项目 |
| 一个 `.mp4` 视频 | 相册 → 最近项目 |
| 一个 `.pdf` / `.zip` | 文件 App → 我的 iPhone → MyTransfer |

首次运行弹「允许访问本地网络」→ 允许；弹「允许访问照片」→ 允许所有。
电脑窗口日志出现 `[OK] 字节数 xx/xx 一致` = 校验通过，全部成功。

## 出错对照表

| 手机报错 | 原因 | 修法 |
|---|---|---|
| 无法将文本转换为词典 | 「如果」输入选了整段 JSON | If 输入改选 hasFile 的「词典值」 |
| 无法将媒体转换为词典 | kind 那步在下载之后 | 把 kind 挪到下载上面（第 6 步位置） |
| 都进了文件没进相册 | 扩展名取了下载文件（恒为空） | 扩展名用 fileName 匹配文本；加 kind 兜底 |
| 存出小 json 文件 | 保存输入选了 status 的 URL 内容 | 改选下载那步的「URL 的内容」 |
| 无法将多信息文本转换为 URL | complete 网址框里有变量 | 清掉，纯键盘打字 |
| 第一步就失败/超时 | 电脑没开 / 不同 Wi-Fi | 用 Safari 测准备第 3 条那个地址 |

## 换电脑 / 换网络

网址里的 `MyTransfer.local` 跟着电脑的 Bonjour 名字走，电脑换 IP **不用改**。
只有换一台电脑当服务器时，才把 2 处网址里的 `MyTransfer.local:8765` 换成新电脑 `IP:8765`。
